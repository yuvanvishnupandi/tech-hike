## Getting Started

First, ensure you have [Node.js](https://nodejs.org/) installed on your machine.

Clone the repository and install the minimal dependencies:

```bash
$ npm install
```

Run the local development server:

```bash
$ npm run dev
```

The application will be served at `http://localhost:3000` (or the port specified by the output).

## Features

- **Fluid Typography & Spacing** - Fully responsive design using modern CSS clamp techniques for a seamless experience across all device sizes.
- **Smooth Scrolling** - Zero-dependency smooth anchor navigation and animated viewport reveals.
- **Zero-Dependency Core** - Built entirely with vanilla HTML, CSS, and lightweight JS for maximum performance.
- **Media Optimized** - Dynamic video backgrounds and optimized asset delivery for lightning-fast load times.
