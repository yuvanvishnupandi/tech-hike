# Tech Hike

A responsive landing page for Tech Hike, built with vanilla HTML, CSS, and JavaScript.

[Live Site](https://tech-hike.vercel.app/)

## Install

```bash
$ git clone https://github.com/yuvanvishnupandi/tech-hike.git
$ cd tech-hike
```

## Usage

Open `index.html` directly in a browser, or serve the project with a local development server.

## Features

- **Responsive Layout** — Adapts across desktop, tablet, and mobile screen sizes.
- **Smooth Scrolling** — Provides smooth navigation between sections.
- **Fluid Typography** — Uses responsive sizing and spacing with CSS.
- **Animated Sections** — Adds lightweight viewport-based reveal effects.
- **Media Assets** — Uses custom images, fonts, and video assets throughout the page.
